# Dữ liệu dùng chung

Thư mục này chứa các bộ dữ liệu nền lớn được nhiều dự án sử dụng. Người dùng chỉ bổ sung hoặc cập nhật dữ liệu khi tài liệu dự án yêu cầu.

- soil_type_vietnam/: Soil Type toàn Việt Nam.
- Tệp trong raw/ chỉ nằm trên máy này, bị Git bỏ qua và không được đẩy lên GitHub.
- Mỗi dự án vẫn có thể cung cấp soil_type.geojson riêng trong 01_THIET_KE_LAY_MAU/01_DAU_VAO; dữ liệu dự án riêng được ưu tiên.
